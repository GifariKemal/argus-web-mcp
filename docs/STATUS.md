**No LLM needed (architecture):** Argus is tools-not-brain - the consuming agent (Claude Code / Codex) does synthesis from `research(deep)`/`quick` raw-content bundles. Argus's LLM tier (research `answer`, extract_structured `llm`) is OPTIONAL, **off by default** (requires `ARGUS_ENABLE_LLM=1` + endpoint), so Argus is fully functional with zero LLM. Not a deploy dependency.

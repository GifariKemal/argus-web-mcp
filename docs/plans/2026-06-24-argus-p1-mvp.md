# Argus P1 - MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [ ]`) syntax. TDD throughout. Ponytail discipline: stdlib -> native -> installed dep -> one line -> minimal code. Never cut validation / SSRF / error handling.

**Goal:** A running FastMCP server (stdio for local dev) exposing 6 web tools (`read, search, read_pdf, scrape, batch_read, extract_structured`), SSRF-hardened, cache-backed, that beats free competitors on the benchmark - all validated locally before any VPS touch.

**Architecture:** Layered. `security/ssrf` is the trust boundary every fetch passes through. `fetch/` is tiered (httpx static -> Crawl4AI/Playwright render) with a shared Chromium pool in the FastMCP lifespan + an `asyncio.Semaphore`. `extract/` turns raw HTML/PDF into clean markdown / structured JSON. `cache` is content-addressed (SQLite index + disk blobs), store-good-only with stale-serve. `search` calls a local SearXNG Docker. `server.py` wires it all into MCP tools.

**Tech Stack:** Python 3.12 (uv-managed venv), fastmcp, crawl4ai (+Playwright), trafilatura, readability-lxml, markdownify, httpx, pymupdf4llm, docling, parsel, pydantic, pytest/pytest-asyncio/pytest-cov, respx (httpx mocking), ruff.

> **Execution mode (owner directive - full-autonomous, multi-agent):** Components with disjoint files are fanned out to parallel subagents that each own one module + its tests and build it TDD to the **contract** locked in sec "Module Contracts" below. The orchestrator builds the skeleton (Task 1) first (everyone depends on it), then dispatches Tasks 2/3/4/6/9 in parallel, then 5 (needs ssrf+extract), then 7 (integration), then 8 (cross-module integration tests). Contracts are frozen so parallel work cannot collide.

## Module Contracts (FROZEN - parallel agents build to these)

### `src/argus/models.py`
```python
from pydantic import BaseModel

class ToolError(BaseModel):
    error: str          # human message
    code: str           # ssrf_blocked|fetch_failed|empty_content|not_pdf|parse_failed|
                        # search_backend_down|no_results|schema_invalid|extraction_failed|render_failed|blocked_by_antibot
    detail: str | None = None

def err(code: str, message: str, detail: str | None = None) -> dict:
    """Structured error dict returned to MCP client - NEVER raise to client."""
    return ToolError(error=message, code=code, detail=detail).model_dump()
```

### `src/argus/security/ssrf.py` - TRUST BOUNDARY
```python
class SSRFError(Exception):
    code = "ssrf_blocked"

ALLOWED_SCHEMES = {"http", "https"}

def validate_url(url: str) -> None:
    """Scheme allowlist + host present. Raises SSRFError. Does NOT resolve DNS (cheap pre-check)."""

def resolve_and_validate(host: str, port: int) -> list[str]:
    """Resolve host (getaddrinfo), return list of allowed IP strings.
    Raise SSRFError if ANY resolved IP is private/loopback/link-local/reserved/multicast
    or a cloud-metadata addr (169.254.169.254, fd00:ec2::254). Block-on-any (no partial)."""

def is_blocked_ip(ip: str) -> bool:
    """True if ip  in  private/loopback/link-local/reserved/multicast/metadata. Pure, fully unit-tested."""

def build_safe_async_client(**kwargs) -> "httpx.AsyncClient":
    """httpx.AsyncClient whose transport: (1) on every request AND every redirect hop,
    resolves+validates the host, (2) PINS the connection to a validated IP while keeping the
    original Host header + TLS SNI (anti-DNS-rebinding). follow_redirects handled manually so
    each hop is re-validated. Default timeout, max_redirects=5."""
```
Anti-rebinding pin technique: custom `httpx.AsyncBaseTransport` that wraps `AsyncHTTPTransport`; on `handle_async_request` it reads `request.url.host`, calls `resolve_and_validate`, rewrites the request URL host->pinned IP, sets `Host` header to the original host and `request.extensions["sni_hostname"]=original_host`. Redirects are followed in `core.py` (not by httpx auto) so each Location is re-`validate_url`+`resolve_and_validate`'d.

### `src/argus/cache.py`
```python
class Cache:
    def __init__(self, db_path: str = "~/.argus/cache.db", blob_dir: str = "~/.argus/blobs"): ...
    def key(self, url: str, opts: dict) -> str:
        """sha256 of canonical(url)+sorted-opts -> content-addressed key."""
    def get(self, key: str, ttl_seconds: int) -> dict | None:
        """Return cached payload if fresh (age < ttl). None if missing/expired."""
    def get_stale(self, key: str) -> dict | None:
        """Return cached payload regardless of age - for stale-serve on transient fetch failure."""
    def put(self, key: str, payload: dict, source: str) -> None:
        """Store ONLY successful payloads (store-good-only). Large content -> disk blob, index in SQLite."""
```
Per-source TTL map lives in cache (e.g. `news=900, docs=86400, trading=300, default=3600`); `ttl_for(category)` helper. Use stdlib `sqlite3` + `hashlib` + `json` + disk files - no ORM.
